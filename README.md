# ICED-2027
This repository contains the data created and used for the publication "Potential and limits of publicly available product documentation for early feasibility assessment in repurposing"

## Abstract

In a circular economy, repurposing extends product lifecycles and reduces resource use. Assessing whether a product meets the requirements of a target application before physical inspection requires accessible product information. This study investigates to what extent publicly available technical product documentation provides this information, using notebooks repurposed as thin clients as a case study. Twenty notebook variants were assessed. One variant was examined on an extended documentation basis and repurposed in practice. Requirements referring to single property values were assessable for all variants, whereas those depending on product structure or function often were not, since dependencies between components only become visible in the new system. Such documentation therefore supports excluding unsuitable variants but cannot confirm feasibility.
